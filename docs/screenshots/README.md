# Screenshots

README では以下のファイルを参照しています。

- `iphone-main.png`
- `carplay-main.png`

追加ルールです。

- 画像はできれば PNG を使う
- ファイル名は README と一致させる
- 差し替え時は同名で上書きする
- 別画面を追加する場合は README に画像リンクを追記する

例:

```md
![iPhone main screen](docs/screenshots/iphone-main.png)
![CarPlay main screen](docs/screenshots/carplay-main.png)
```

リポジトリに画像を残したくない場合は、このディレクトリを `.gitignore` に追加してください。
